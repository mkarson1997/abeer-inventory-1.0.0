# Contributing

1. Fork the repository and create a focused branch.
2. Use Python 3.11+ and install `pip install -e '.[dev]'`.
3. Run `pytest` and `ruff check .` before submitting a change.
4. Do not commit `instance/`, databases, uploaded images, `.env`, or secrets.
5. Add or update tests for behavior changes.
6. Keep user-facing text available for Arabic, Turkish, and English where practical.
