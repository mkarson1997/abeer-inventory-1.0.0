# Changelog

## 1.0.0 - 2026-08-20

- Rebuilt the original local stock-tracking prototype as Abeer Inventory.
- Added roles, secure sessions, CSRF, login throttling, audit history, safe image processing,
  safe Excel/PDF exports, in-memory barcodes, multilingual UI, Docker, tests, backup and legacy
  migration commands.
- Runtime databases, legacy users, uploaded media, credentials, and virtual environments are not
  included in the open-source package.
